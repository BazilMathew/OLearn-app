# Narration clips

Every tutorial step's narration is a bundled MP3 in `public/assets/audio/<lang>/`, generated by `scripts/generate-audio.py` with edge-tts (Microsoft Edge's online neural voices; no API key). The script reads `src/config/tasks.json`: each step's `audio_<lang>` path is the clip's file name and its `hint_text[lang]` is what it says, so the captions and the voice never drift apart. Before speaking, the script makes a few changes to the text, and only to the text it speaks (tasks.json is not changed): `₹1,000` becomes "1,000 rupees" / "1,000 रुपये" / "1,000 രൂപ", quotes around button names are dropped, and "Ramesh (Son)" is read as "Ramesh, Son". It retries each clip 3 times and exits with an error if any clip fails or is under 3 KB.

One voice per language, all at `-10%` speed: English `en-IN-NeerjaNeural`, Hindi `hi-IN-SwaraNeural`, Malayalam `ml-IN-SobhanaNeural`. Each language has 37 clips. `node --import tsx scripts/audit-tutorials.mjs --audio-only` checks that every clip path in tasks.json is a git-tracked file with the exact case, and that all three languages have the same clips.

To redo clips, install edge-tts (`pip install edge-tts`) and run `python scripts/generate-audio.py --lang ml --only gpay_bal_step3`. `--only` can be repeated, and either flag can be left out: without `--lang` it covers every language, and with no flags it regenerates everything. To change what a clip says, edit its `hint_text` in tasks.json and regenerate it. Then `git add` the new files and run the audit.
